API & Integrations

Connect Lawcall to Cloudflare securely. Do not paste API tokens into this dashboard or GitHub.

Cloudflare Worker secrets

Open Cloudflare Dashboard → Workers & Pages → lawcall2 → Settings → Variables and Secrets. Add credentials there as Secret values, not plain text variables.

Open Cloudflare dashboard ↗
R2 storage

For private intake files, the Worker currently has an R2 binding named FILES connected to the lawcall bucket. Private document upload endpoints and per-firm authorization are not enabled yet.

Voice provider

Groq powers speech generation and transcription. Add GROQ_API_KEY as a Cloudflare Worker Secret. Telnyx will provide phone numbers and call control; add TELNYX_API_KEY as a Worker Secret. For protected server-to-server voice tests, also add LAWCALL_INTERNAL_API_TOKEN as a random secret of at least 32 characters. Never put that token in browser code.

New inquiry opens a fillable demo form and saves fictional test entries to D1. Use made-up details only; real client intake remains disabled until authenticated firm accounts, tenant isolation, and protected file access are implemented and tested.
